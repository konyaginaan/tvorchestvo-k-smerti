# Творчество к смерти

Сайт к психоаналитическому докладу по роману Патрика Зюскинда «Парфюмер»: Жан-Батист Гренуй и мир частичных объектов. Конягина Анастасия, декабрь 2026.

https://konyaginaan.github.io/tvorchestvo-k-smerti/

`index.html` собирается из `template.html` скриптом `build.py`: он подставляет заметки из базы Obsidian «купс группа» и полные тексты глав из заметки с докладом. После правок в базе — `python3 build.py`, затем коммит и пуш.
